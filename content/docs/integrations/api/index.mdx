title: "API Anbindung"
---

Über die Zählerfreunde-API binden Sie Ihre bestehenden Systeme (z. B. ERP oder Abrechnungssystem) direkt an unsere Plattform an. Damit können Sie Kunden automatisiert onboarden, deren Verträge, Objekte und Zähler anlegen und Messwerte übertragen – ganz ohne manuelle Pflege im Admin-Portal.

Die folgenden Seiten führen Sie in der empfohlenen Reihenfolge durch eine Standard-Integration. Die Schritte lassen sich an Ihre bestehenden Prozesse und Tools anpassen.

## API-Referenz

Die vollständige Referenz aller Endpunkte mit Schemas und Beispielanfragen finden Sie in der [API-Dokumentation](/rpcapi/create-api-token). Die in dieser Anleitung verwendeten Endpunkte:

| Schritt | Endpunkt | Referenz |
| --- | --- | --- |
| Authentifizierung | `POST /auth/token` | [Create auth token](/rpcapi/create-api-token) |
| Stammdaten | `POST /customers` | [Upsert customer](/rpcapi/add-update-customer) |
| Stammdaten | `POST /customers/{customerId}/contracts` | [Create customer contract](/rpcapi/add-customer-contract) |
| Messdaten | `POST /devices/readings` | [Store readings](/rpcapi/store-readings) |

Alle Endpunkte liegen unter der Basis-URL `https://external.prod.zaehlerfreunde.com/partner`.
